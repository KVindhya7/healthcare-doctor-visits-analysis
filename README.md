# Healthcare Analytics for Doctor Visits

A beginner-friendly data analysis project exploring a healthcare survey dataset of 5,190 people, using **Python**, **Pandas**, **NumPy**, **Matplotlib**, and **Seaborn** in a **Jupyter Notebook**.

The project looks at who visits the doctor, how often, and what factors — age, gender, illness, chronic conditions, and insurance status — relate to doctor visit frequency.

## Getting started (VS Code + Jupyter)

1. **Install Python 3.9+** if you don't already have it.
2. **Open this folder in VS Code.**
3. **Install the Jupyter extension** for VS Code (search "Jupyter" in the Extensions panel) if you don't have it.
4. **Create a virtual environment** (recommended) and install dependencies:

   ```bash
   python -m venv venv
   source venv/bin/activate        # on Windows: venv\Scripts\activate
   pip install -r requirements.txt
   ```

5. **Open `notebooks/doctor_visits_analysis.ipynb`** in VS Code, choose your virtual environment as the kernel (top-right of the notebook), and run all cells (`Run All`).

## How to use this project

- Run the notebook top to bottom — every cell is self-contained and produces its own output or chart.
- Keep `docs/EXPLANATIONS.md` open in a side tab for a plain-language explanation of *why* each step matters.
- Check `docs/DATA_DICTIONARY.md` any time you forget what a column means.

## Dataset

`data/doctor_visits.csv` is the classic **DoctorVisits** health survey dataset (Australian Health Survey), widely used for teaching healthcare-utilization and count-data analysis. See `docs/DATA_DICTIONARY.md` for column definitions.
